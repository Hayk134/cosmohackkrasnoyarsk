## 🛰 О проекте и проблематика

На развивающемся углеродном рынке ключевыми препятствиями для инвесторов и верификаторов являются **гринвошинг**, **непрозрачность расчетов** и **высокая погрешность спутниковых данных**. Классические подходы часто допускают грубые ошибки:
* Расчет площадей в плоских координатах или по градусной сетке без учета сжатия эллипсоида Земли (ошибка до 40% на широтах РФ).
* Простое суммирование погрешностей пикселей без учета пространственной автокорреляции ошибок (занижение реальной неопределенности в 3–5 раз).
* Отсутствие автоматической фиксации скрытых пожаров и несанкционированных рубок.

**Kosmo·MRV** — это веб-сервис спутниковой верификации лесоклиматических проектов и углеродных единиц институционального уровня на основе реальных геоданных:
* **ESA CCI Biomass v7.0** (годовые карты надземной биомассы AGB и неопределенности AGB_SD с 2015 по 2024 гг.).
* **Copernicus Sentinel-2 L2A** (мультиспектральные каналы с поправкой на радиометрический сдвиг и фильтрацией облаков по SCL).
* **NASA MODIS MCD64A1 v6.1** (битовые маски QA и суточные даты выгорания за 2021 г.).
* **Hansen Global Forest Change 2025 v1.13** (динамика потери лесного полога с 2001 по 2024 гг.).

## 🧮 Математический алгоритм вычисления (Шаг за шагом)

Расчетный конвейер строго следует принципам **МГЭИК (IPCC 2006, Том 4)** и условиям технического задания хакатона:

### Шаг 1. Аналитическая геодезия на эллипсоиде WGS 84
Земля представляет собой сплюснутый у полюсов эллипсоид вращения. На широте $56^\circ$–$60^\circ$ с.ш. градус долготы сжат почти в два раза относительно экватора. Принятие площади пикселя равной $1\text{ га}$ недопустимо.
* Площадь рассчитывается интегрированием дифференциала площади по эллипсоиду:
  $$S = \frac{a^2(1 - e^2)\Delta\lambda}{2e} \cdot \left[ q(e\sin\phi_2) - q(e\sin\phi_1) \right]$$
  где $q(u) = \frac{u}{1 - u^2} + \frac{1}{2}\ln\left(\frac{1 + u}{1 - u}\right)$ — аутелическая функция широты на эллипсоиде WGS 84 ($a = 6378137.0\text{ м}$, $e^2 \approx 0.00669438$).
* Для граничных пикселей вычисляется **субпиксельный вес** (доля пересечения полигона с ячейкой растра).

### Шаг 2. Перевод биомассы в запас углерода и эквивалент $\text{CO}_2$
* Основной пул охватывает сухую надземную древесную биомассу (AGB).
* Перевод в чистый углерод по нормативу МГЭИК: $CF = 0.47\text{ т C / т сухого вещества}$.
  $$c_{i,t} = b_{i,t} \cdot 0.47 \quad [\text{т C/га}]$$
* Суммарный запас на полигоне: $C_t = \sum a_i c_{i,t}\text{ [т C]}$.
* Изменение запаса: $\Delta C = C_{t_1} - C_{t_0}\text{ [т C]}$.
* Проектные нетто-выбросы/поглощения в $\text{CO}_2$-эквиваленте (стехиометрия $44/12$):
  $$E_{proj} = -\Delta C \cdot \frac{44}{12} \quad [\text{т CO}_2\text{e}]$$
  *(Отрицательное значение означает сток/накопление углерода в лесу).*

### Шаг 3. Контрфактическая базовая линия (Baseline Counterfactual)
* По исторической динамике 2015–2019 гг. рассчитывается среднегодовой темп $g = \frac{\bar{c}_{2019} - \bar{c}_{2015}}{4}\text{ [т C/га/год]}$.
* Проекция базового запаса: $c_{base}(y) = \max(0, \, \bar{c}_{2019} + g \cdot (y - 2019))$.
* Базовые выбросы: $E_{base} = -A \cdot (c_{base}(t_1) - c_{base}(t_0)) \cdot \frac{44}{12}\text{ [т CO}_2\text{e]}$.
* **Валовый углеродный эффект проекта:**
  $$R = E_{base} - E_{proj} - LK \quad [\text{т CO}_2\text{e}]$$
  *(где $LK = 0$ — нормативно заданное допущение об отсутствии утечек).*

### Шаг 4. Пространственная автокорреляция ошибок (Индекс Морана и VIF)
Ошибки спутниковых растров ($AGB\_SD$) пространственно зависимы (кластеризуются из-за дымки и рельефа). Простое сложение дисперсий занижает ошибку в разы.
* Алгоритм вычисляет **2D глобальный индекс Морана** по окрестности Мура (Queen, 8 соседей):
  $$I = \frac{N}{S_0} \cdot \frac{\sum_i \sum_j w_{ij} (z_i - \bar{z})(z_j - \bar{z})}{\sum_i (z_i - \bar{z})^2}$$
* Дисперсионный инфляционный фактор Клиффорда-Орда:
  $$VIF = \max\left(1.0, \, \min\left(N, \, \frac{1 + I}{1 - I}\right)\right)$$
* Стандартная ошибка проекта:
  $$SE(E_{proj}) = \frac{44}{12} \cdot \sqrt{CF^2 \cdot VIF \cdot \sum_i a_i^2 (SD_{t_0,i}^2 + SD_{t_1,i}^2)}$$
* Полуширина 95% доверительного интервала: $H = 1.95996 \cdot SE(E_{proj})$. Доверительный интервал: $[L, U] = [E_{proj} - H, \, E_{proj} + H]$.

### Шаг 5. Защитные шлюзы и отсечение гринвошинга
1. **Шлюз отсутствия эффекта:** Если $R \le 0$ (лес сгорел или деградировал), выпуск единиц блокируется: **$Q = 0$**, отношение $H/R$ подавляется.
2. **Шлюз высокого шума:** Если отношение неопределенности к сигналу $H/R \ge 1.0$, выпуск единиц блокируется: **$Q = 0$**.
3. **Шлюз неполного покрытия:** При выходе полигона за границы растра расчет единиц блокируется (`INCOMPLETE_COVERAGE`).

### Шаг 6. Вычет за неопределенность и буферный резерв
* **Вычет за риск (UNC Haircut):** Допустимый порог без вычета — 10% ($0.10$).
  $$UNC = \min\left(1.0, \, \max\left(0.0, \, \frac{H}{R} - 0.10\right)\right)$$
* Скорректированный эффект: $R_{adj} = R \cdot (1 - UNC)$.
* **Буферный резерв постоянства ($B = 15\%$):** Замораживается на случай будущих ЧП:
  $$B = 0.15 \cdot R_{adj} \quad [\text{т CO}_2\text{e}]$$

### Шаг 7. Выпуск обращаемых единиц ($Q$) и монетизация
* Объем потенциальных единиц округляется **строго вниз до целого числа**:
  $$Q = \left\lfloor R_{adj} - B \right\rfloor = \left\lfloor 0.85 \cdot R_{adj} \right\rfloor$$
* Сценарная стоимость выпуска: $V_{500} = Q \times 500\text{ ₽}$, $V_{1500} = Q \times 1500\text{ ₽}$, $V_{4000} = Q \times 4000\text{ ₽}$.

### Шаг 8. Криптографический аудит (SHA-256)
Все параметры расчета, геометрия и результаты пакуются в канонический JSON и запечатываются хэшем SHA-256, исключающим фальсификацию верификационного отчета.

## 💼 Комплекс B2B и FinTech модулей

В платформе развернут пакет из **10 институциональных инструментов**:
1. **Инвестиционный калькулятор Carbon ROI & CAPEX/OPEX:** 15-летняя динамическая финансовая модель с ползунками затрат на саженцы и уход. Расчет точки безубыточности, **NPV** и **IRR** (10–15%). Сравнение доходности: *«Климатический проект»* против *«Сплошная рубка на древесину»*.
2. **Параметрическое смарт-страхование:** Автоматический триггер выплаты при выгорании $>10\%$ площади по $dNBR$/MODIS с покрытием из накопленного 15% буферного пула.
3. **Интерактивная карта-шторка (Swipe Tool):** Попиксельное сопоставление состояния леса 2019 vs 2024 гг. в видимом спектре Sentinel-2 и теплокарте биомассы.
4. **Зеркальный контрольный участок (Dynamic Baseline Matching):** Автоматический подбор внешнего парного участка без мер охраны для железобетонного подтверждения принципа дополнительности (**Additionality**).
5. **AI-классификатор породного состава:** Мультиспектральная классификация Sentinel-2 (каналы B02, B03, B04, B8A, B11, B12) с дифференциацией хвойных и лиственных пород и автоподстройкой $CF \in [0.45; 0.51]$.
6. **Радар раннего предупреждения пожаров и рубок:** Мониторинг термических точек NASA FIRMS и когерентности Sentinel-1 SAR сквозь сплошную облачность.
7. **Климатические риски до 2050 года (IPCC CMIP6):** Проекция гидротермического коэффициента и риска засухи по сценариям SSP2-4.5 и SSP5-8.5.
8. **Цифровой «Зеленый паспорт участка»:** Публичный верификационный паспорт с динамическим векторным QR-кодом для корпоративной ESG-отчетности.
9. **Экспорт пакета по ГОСТ Р ИСО 14064-2:** Машиночитаемая выгрузка в форматах XML и JSON для прямой загрузки в Реестр углеродных единиц РФ.
10. **AI-скаут новых территорий:** Экспресс-скоринг кадастровых контуров под карбоновые фермы по потенциалу прироста и рискам.

## 🌐 Интеграция с открытыми каталогами STAC

В соответствии с требованиями ТЗ реализован клиент к открытым каталогам спутниковых данных:
* **AWS Earth Search STAC API (`sentinel-2-l2a`):** Прямой поиск сцен по координатам BBox, датам и облачности через эндпоинт `/api/open-data/sentinel2/search`.
* **Microsoft Planetary Computer STAC API (`modis-64A1-061`):** Каталогизация суточных продуктов гарей.
* **Отказоустойчивое кэширование:** При недоступности внешней сети сервис бесшовно использует сохраненный локальный каталог `scene_metadata.json` и `sources.csv`.

## 🚀 Инструкция по установке и локальному запуску

### Системные требования
* **ОС:** Windows 10/11, macOS, Linux (Ubuntu 20.04+).
* **Python:** 3.10, 3.11, 3.12, 3.13 или 3.14.
* **Node.js:** v18.0+ или v20.0+ и npm.

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/Hayk134/cosmohackkrasnoyarsk.git
cd cosmohackkrasnoyarsk
```

### Шаг 2. Запуск Backend (FastAPI)
```bash
# Создание и активация виртуального окружения
python -m venv .venv

# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
```
* Backend доступен по адресу: `http://127.0.0.1:8000`
